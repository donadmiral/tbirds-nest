REPAIRS

React export
The iOS image-capture path can be an absolute filesystem path without a file:// prefix. The reaction export validator rejected that valid capture path, causing the invalid-request error shown in the screenshot. The export boundary now normalizes and escapes local paths for captured layers, the source and the camera recording. Export failure continues to preserve the recorded take for retry.

Feed videos and images
The old shared-player replacement could briefly expose the previous video's frame. The new bounded player pool keeps each player attached to its own exact source, allows one audible owner, and prepares up to two upcoming videos. A card retains its own poster until that source delivers its first frame. Source identities guard asynchronous completions, recycled images, failures and retries. Navigation, account changes and backgrounding release stale players. Nearby web videos load ahead while far-away videos avoid unnecessary loading.

Stories
The story strip prepares the first unseen story before entry and reuses the in-flight request when tapped. Short-lived, account-scoped readiness data and a bounded native iOS warm-player pool prepare upcoming content. Playback keeps the correct poster through the saved trim seek and first-frame delivery. Photo callbacks are tied to the current source and retry. Author metadata no longer blocks opening media.

Memory books
The album authorization already covers retained story pages. Redundant per-story authorization work is now removed for those covered pages, with separate authorization retained for embedded posts and unrelated stories. Bounded concurrent media signing avoids sequential batches. Covers use a matching thumbnail when available, and the next native clips are prepared ahead. Native and web film playback retains the correct cover/poster until the required frame is available.

Thumbnails and messages
Thumbnail work has bounded concurrency and queue size, source-bound rendering, a time-bounded visible fallback, and account-scoped cleanup. A timed-out native decoder cannot silently exceed the concurrency limit.
Inbox and chat text can render before attachment and group-photo grants finish. Late avatar results update only photo fields and cannot overwrite newer conversation text or unread state. Private attachments remain withheld until authorized.
