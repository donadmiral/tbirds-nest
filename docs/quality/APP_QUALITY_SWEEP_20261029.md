# Platinum Circles app quality sweep — 29 October 2026

## Current decision

**TestFlight is on hold.** This pass implements verified repairs and partial improvements, and records the remaining work before the app can be considered complete. It does not claim that every feature has passed physical iPhone acceptance, and it does not create, submit or release a new iPhone build. The currently installed iPhone app does not contain these new client changes.

Source branch: `codex/app-quality-20261029`, reviewed in [draft PR #3](https://github.com/donadmiral/tbirds-nest/pull/3) in [donadmiral/tbirds-nest](https://github.com/donadmiral/tbirds-nest). It began at production source `9906c187521c59254277a00571bded3c8db49b98` and includes the subsequent production hotfixes. Four narrow database repairs are live. The web/admin dependency security patch ([PR #4](https://github.com/donadmiral/tbirds-nest/pull/4)) and admin support capability guard ([PR #5](https://github.com/donadmiral/tbirds-nest/pull/5)) are also live. The broader native/web/admin feature changes remain draft source and have not been promoted to production or installed on an iPhone.

This is the current quality decision. Earlier release-evidence files in this repository are historical checkpoints and are not evidence that this pass has reached the user's satisfaction or that its new source is installed.

## Additional bugs repaired in the wider sweep

- **Saved Posts:** authorized signing and renewal, truthful loading/error states, retry, account fencing and independent rollback for concurrent unsaves.
- **Search:** stale-result prevention, category-specific errors, block-setting failure handling, signed media, account-scoped recent searches and direct navigation to the selected job.
- **My Network:** replaced inaccessible community table operations with the existing authorized community APIs, added checked create/join/leave/cancel outcomes, independent directory retries and correct Community destinations.
- **Navigation fallbacks:** Search and Saved Posts now return to actual registered root/tab/child routes when no history exists. Tests execute the real Back handlers in both cases.
- **Edit Profile:** saves wait for uploads, duplicate writes are guarded, affected rows are checked, failed loads cannot become blank editable profiles, and late account responses cannot overwrite a later account/draft.
- **Seller history:** a failed read no longer means zero reviews, zero sales or a new seller. Reads have time limits, stay scoped to the seller and offer retry.
- **Comments:** drafts/GIFs/reply context survive failed sends; same-tick duplicate sends are blocked; moderation failures are visible; old callbacks cannot apply to a replacement thread/account; action rows wrap and have usable touch targets. Final review also fenced Restrict confirmations/results against account changes and made web comments respond immediately to auth identity changes without discarding drafts on same-account token refreshes.
- **Story engagement:** corrected the missing sticker summary function; removed obsolete notification wiring; Add yours links only after confirmed publication; speed-only edits persist; denied/failed countdown scheduling cannot claim success; question drafts survive send failure; owner settings require a confirmed affected row.
- **Studio:** four native/web device actions now use the live `p_action: approve/remove` contract.
- **Diagnostics:** the missing redacted reporting RPC is installed. Identity is derived on the server, free-form message/stack content is discarded, direct device table access is revoked, and deduplication/rate limits are enforced.
- **Admin workflows:** restored the four support assignment and seller-review report/moderation contracts after exact-baseline tests. The deployed support page distinguishes working assignment controls from unavailable reply/status commands. General admin commands, provisioning and the deletion queue still explain their unavailable state accurately; they do not imply empty queues or successful changes.
- **Web-only installation:** the initial draft CI exposed a shared memory hook importing React outside the web dependency boundary. A React-independent shared factory and thin native/web wrappers now pass an isolated web install and a regression test with a failing negative control for the original defect.
- **Dependency security:** patched web/admin Next.js and Sharp, verified both zero-entry registry audits and deployed the four-file security patch. Compatible native dependency updates and removal of an unused Zod dependency reduce the root audit from 32 to 24 entries. A checked deep-link entry point rejects malformed/oversized input before the old Navigation decoder; the vulnerable transitive package still requires compatible toolchain maintenance.
- **Settings truthfulness:** Rate the App identifies public-release availability. Account deletion no longer promises stored-file erasure that the current backend does not perform.

## Work still required before a complete release

### 1. Finish video and memory audio/export

The photo editor is materially repaired. Video color grading remains unavailable on both native and web. Encoding video plus stickers/text/drawings/audio into one output movie is also unfinished. Memory playback remains an opt-in book that stops at its last page, and saved embedded post videos are not yet an automatically composed memory-film sequence. The requested continuous movie-style presentation needs an implemented media pipeline and real-device output comparisons. The app now describes the current limits instead of implying an edited export exists.

Licensed background music also remains unavailable. `MUSIC_CATALOG_ENABLED = false` stays in place. Continuous soundtrack coordination cannot supply licensed songs on its own. The outstanding work is the catalogue/rights/provider contract and audible native/web acceptance, including interruption, trim and background behavior. Apple Music subscription playback is not substituted for the requested social-app music catalogue.

### 2. Complete private media delivery and account erasure

The inspected `post-media`, `story-media` and `media` buckets are still public. Row authorization and newly signed client URLs do not prove that a known public object URL is inaccessible. A coordinated private-bucket cutover, client compatibility check, cache handling and unauthorized URL tests are required. Switching buckets during a hold while older installed clients still depend on them risks breaking those clients; this pass does not make that untested cutover.

The live `delete_user_account` function deletes database/account rows but does not erase Storage objects. Accurate UI copy is fixed; complete deletion is not. A retryable storage-erasure workflow, retention decisions, failure recovery and verification must be implemented and tested before claiming all stored files are removed.

### 3. Complete the remaining admin operations contracts and staff acceptance

Three active admin contracts remain absent: central admin commands, provisioning and the deletion-request queue. Two finance-admin contracts are additionally absent behind their disabled gate. The four support-assignment and seller-review contracts are now restored and postflight-verified, with the corresponding capability UI live; actual staff-session acceptance is still required. Support reply/solve/reopen remain unavailable because they depend on the central command contract.

The broad admin/provisioning migration remains undeployed. The reviewed evidence does not contain an automatic-review rejection specific to that admin migration; earlier wording attributing this admin gap to such a rejection was unsupported. The recorded rejected units concern music rights and creator finance. Completing the remaining admin scope requires a current-baseline implementation with its moderation, verification and staff-governance guards, plus actual Auth reserve/create/finish acceptance for provisioning. [The restoration assessment](ADMIN_RESTORATION_FEASIBILITY_20261029.md) details that work.

### 4. Verify provider and real-device behavior

Actual iPhone acceptance must cover the originally reported media, story Text/cancel/share, every photo adjustment after crop and reopening, Photos export, multi-touch stickers, automatic memory playback, send destinations, message Back/Cancel/Next, feed-tab changes, profile photo navigation, and all three color palettes.

CameraKit/lens entitlement, actual camera capture, APNs/notifications, CallKit/call interruptions, Photos permissions and external finance/music providers require their real environments. Configuration presence and simulated adapters do not prove provider completion. Two-device tests need intentional test conversations, not unsolicited messages to other people.

### 5. Close the remaining database hardening and product-quality checks

The current security advisor reports 61 functions with mutable search paths, 216 anonymous-executable security-definer entries, 377 authenticated-executable entries, one extension in the public schema and disabled leaked-password protection. These are audit candidates, not proven exploitable vulnerabilities: many checked RPCs are deliberately executable, and trigger functions are not ordinary public commands. Fifty-two RLS-without-policy findings include intentionally private tables, the closed diagnostics table and the two new admin tables. Review exposed functions by their actual identity checks and privileges instead of granting access or changing them all indiscriminately.

Web and admin registry audits now report zero entries, and those dependency patches are live. Native/root still reports **24 entries: zero critical, six high, seven moderate and eleven low**, arising from five underlying packages and their dependency paths. The configured external-link entry is now guarded, but the vulnerable decoder package remains installed; image-size, PostCSS, deepmerge and uuid require a compatible Expo/Metro/toolchain maintenance plan and focused native validation. Audit counts are dependency entries, not 24 distinct exploitable app bugs. See [the dependency security audit](DEPENDENCY_SECURITY_AUDIT_20261029.md).

Complete device measurements for cold launch, feed scroll, memory playback, large photos/videos, slow/offline recovery and accessibility. The current pass fixes concrete defects and strengthens regression coverage; it cannot certify every visual state, dynamic route or real-world race solely from this environment.
